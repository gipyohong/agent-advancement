# [모아테크] 싸게 산 무선 이어폰, 왜 실패했을까?

| 시간 | 화면 | 내레이션 | 자막 |
|---|---|---|---|
| 0~3초 | 스피커에 둘러싸인 이어폰 실험 장면과 물기 묻은 충전 케이스를 빠르게 교차 편집 | 싸게 샀는데, 왜 또 사게 될까요? | 싸게 샀는데 또 산 이유 |
| 3~8초 | 귀에서 이어폰이 빠지는 장면. 이어팁을 바꿔도 불편한 표정 | 첫 실패는 가격이 아니라 착용감입니다. 오픈형은 고정이 약할 수 있고, 커널형은 귀 모양에 따라 압박과 이탈감이 생길 수 있습니다. [오만상사 후기](https://www.youtube.com/watch?v=7YPJmsQsVn4) | 오픈형: 고정력 확인 / 커널형: 압박감 확인 |
| 8~15초 | 걷거나 뛰며 이어폰을 다시 끼우는 장면, 좌우 ANC 아이콘이 다르게 표시됨 | ANC도 숫자 하나로 끝나지 않습니다. 착용 상태에 따라 좌우 차이가 생길 수 있고, 다시 착용할 때 ANC를 매번 켜야 하는 제품도 있었습니다. [오만상사 후기](https://www.youtube.com/watch?v=7YPJmsQsVn4) | ANC는 착용 상태에 따라 달라짐 |
| 15~23초 | 지하철 소음 파형과 음악 이퀄라이저. 먹먹한 고역대 그래픽 | 음질은 성향을 봐야 합니다. 고역대가 부족하면 먹먹하게 느껴질 수 있고, 타격감 있는 음악에 더 맞는 제품도 있습니다. [오만상사 후기](https://www.youtube.com/watch?v=7YPJmsQsVn4) | 내 음악 장르와 맞나? |
| 23~31초 | 배터리 숫자 두 개를 분할 화면으로 표시. ANC 켬·끔 토글 | 배터리 숫자도 조건이 다릅니다. SoundGuys는 ANC를 켜고 75dBSPL로 시험했고, 제조사 수치는 ANC를 끈 조건인 경우가 많다고 설명합니다. [SoundGuys](https://www.soundguys.com/best-wireless-earbuds-2-14313) | ANC·볼륨·시험 방식 확인 |
| 31~38초 | 음악이 갑자기 멈추고 센서 아이콘에 경고 표시 | 착용 감지 센서가 오작동해 음악이 갑자기 멈춘 사례도 있습니다. 기능 이름보다 실제 사용 후기를 확인하세요. [오만상사 후기](https://www.youtube.com/watch?v=7YPJmsQsVn4) | 센서 오작동 사례 확인 |
| 38~44초 | 스마트폰 코덱 설정 화면과 IPX 표기를 나란히 보여줌 | AAC, aptX, LC3도 이어폰만 보면 안 됩니다. 스마트폰 하드웨어와 OS, 실제 연결 모드를 함께 봐야 합니다. IPX의 X는 방진 항목이 평가되지 않았다는 뜻입니다. [Android Developers](https://developer.android.com/reference/kotlin/android/bluetooth/BluetoothCodecConfig) [IEC](https://iec.ch/ip-ratings) | 코덱은 양쪽 기기 / IPX는 방수 만능 아님 |
| 44~50초 | 체크리스트에 사용 환경, 귀 모양, 스마트폰을 차례로 체크. 마지막은 운동·출퇴근 화면 | 결론은 간단합니다. 가격보다 사용 환경, 귀 모양, 필요한 기능, 내 폰 호환성을 먼저 확인하세요. | 내 귀와 폰부터 확인 |
