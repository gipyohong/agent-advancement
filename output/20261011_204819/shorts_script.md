# [모아테크] 무선 이어폰, 이 5가지만 안 보면 후회합니다

| 시간 | 화면 | 내레이션 | 자막 |
|---|---|---|---|
| 0~3초 | 양손에 가격대가 다른 이어폰을 들고 시작. 화면을 좌우로 나눠 한쪽은 지하철 소음, 다른 쪽은 통화 파형을 보여준다. | 같은 무선 이어폰인데, 잘못 고르면 돈을 두 번 씁니다. | 스펙보다 실패 시나리오 |
| 3~12초 | 운동복 차림의 이어폰과 물방울 그래픽. IPX4와 IPX7을 차례로 띄운다. | 운동용인데 IPX7만 보고 수영까지 하면 안 됩니다. IPX7은 담수 1미터에서 최대 30분 조건이지, 수영이나 샤워 보장이 아닙니다. | IPX7 = 수영 가능 아님 |
| 12~22초 | 이어폰과 스마트폰 사양 화면을 나란히 놓고, 코덱명이 맞지 않는 장면을 연출한다. | LDAC는 이어폰에만 있으면 끝이 아닙니다. 스마트폰과 이어폰 양쪽 공식 지원을 확인하고, 연결 뒤 실제 활성 코덱도 보세요. | 양쪽 지원 + 연결 후 확인 |
| 22~33초 | 새 이어폰의 배터리 숫자와 오래 쓴 이어폰의 짧아진 배터리 아이콘을 대비한다. | 19개월 사용 후기에서는 초기 4시간 이상이던 재생 시간이 왼쪽 약 1시간 2분, 오른쪽 약 1시간 37분으로 줄었습니다. | 신품 수치보다 장기 후기 |
| 33~43초 | ANC 아이콘과 통화 파형을 서로 분리해 보여준다. 이어폰을 끼고 주변을 살피는 장면을 넣는다. | ANC와 통화 품질은 같은 기능이 아닙니다. 통화 품질은 따로 확인하고, 주변 소리를 들어야 할 때는 ANC 사용에도 주의하세요. | ANC ≠ 통화 품질 |
| 43~50초 | 화면에 체크리스트 다섯 개가 순서대로 나타난다. 마지막에 이어폰을 빼는 출퇴근 장면과 운동 장면을 교차 편집한다. | 구매 전 용도, 착용감, 통화 품질, 코덱, 방수 한계, 배터리 후기를 확인하세요. 가격보다 내가 언제 이어폰을 빼는지가 먼저입니다. | 용도·착용감·코덱·방수·배터리 |
