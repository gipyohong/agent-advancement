# [모아테크] 무선 이어폰, 배터리 45시간만 보고 사면 후회합니다

| 시간 | 화면 | 내레이션 | 자막 |
|---|---|---|---|
| 0~5초 | 손에 든 이어폰과 케이스를 나란히 보여준다. ‘45시간’ 표기와 이어버드 아이콘을 번갈아 확대한다. | 배터리 45시간이라 샀는데, 한 번에 45시간 재생되는 게 아니었다면요? | 45시간 = 한 번 충전 45시간? |
| 5~12초 | 체크리스트에 착용감, ANC, 통화 품질, 배터리를 차례로 표시한다. | 먼저 비교할 항목을 고르세요. 착용감, ANC, 통화 품질, 배터리입니다. | 비교 항목부터 고정 |
| 12~20초 | ‘단독’과 ‘케이스 포함’ 칸을 좌우로 분리한다. Xiaomi 수치를 표시한다. | Xiaomi 오픈웨어 스테레오 프로는 이어버드 단독 최대 8.5시간, 케이스 포함 총 45시간으로 따로 표기합니다. [Xiaomi 오픈웨어 스테레오 프로 자주 묻는 질문](https://www.mi.com/kr/support/faq/details/KA-609898) | 단독 8.5시간 / 총 45시간 |
| 20~28초 | Galaxy Buds4 Pro ANC 켜짐과 꺼짐을 비교 그래픽으로 보여준다. | 갤럭시 버즈4 프로도 ANC 켜짐은 단독 최대 6시간, 총 26시간. ANC 꺼짐은 7시간, 총 30시간입니다. [삼성전자, ‘갤럭시 버즈4 시리즈’ 공개](https://news.samsung.com/kr/%EC%82%BC%EC%84%B1%EC%A0%84%EC%9E%90-%EA%B0%A4%EB%9F%AD%EC%8B%9C-%EB%B2%84즈4-시리즈-공개) | ANC ON 6h·26h / OFF 7h·30h |
| 28~35초 | 교환 기간 달력, 고장 난 오른쪽 이어폰 이미지를 보여준다. | 실패 사례도 있습니다. 연합뉴스TV 보도에는 구매 2주 만에 오른쪽 이어폰이 고장 났지만, 일주일이 지나 교환을 거부당한 사례가 나옵니다. [무선 이어폰 해외직구 소비자피해 '급증' / 연합뉴스TV](https://www.youtube.com/watch?v=gUeuR5dsWRQ) | 고장보다 먼저 교환 조건 |
| 35~42초 | IP, 코덱, 블루투스, 교환 조건 체크박스를 표시한다. | 그래서 IP 등급, 지원 코덱, 블루투스 버전은 정확한 모델명과 세대로, 교환 기간은 구매 전에 확인하세요. | 모델명·세대·교환 기간 |
| 42~47초 | 제조사 공식 페이지와 조건이 적힌 후기 화면을 좌우로 보여준다. | 제품별 체감은 제조사 기능 설명과 조건이 공개된 후기를 구분해 확인하세요. | 공식 기능과 후기 조건 분리 |
| 47~50초 | 이어폰을 내려놓고 댓글 입력 화면으로 전환한다. | 당신이 먼저 볼 항목은 무엇인가요? 댓글로 남겨보세요. | 착용감? ANC? 통화? 배터리? |
